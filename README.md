# Jimmy-Toys — інтернет-магазин іграшок і моделей (HTML + CSS + JavaScript)

Відкрийте `index.html` у браузері.

Сторінки: index.html (головна), ai.html (Jimmy AI), collectors.html (колекціонерам),
modeling.html (моделізм), support.html (підтримка).
Стилі: css/style.css. Скрипти: js/main.js. Картинки: папка images/.

## Що додано в практичній роботі № 4 (JavaScript)
- Навігація: бургер-меню з клавіатурним керуванням, підсвічування активної сторінки,
  плавна прокрутка до якорів, кнопка «Нагору», тінь хедера при прокрутці.
- Динамічний вміст: фільтри, сортування й пошук у каталозі, лічильник товарів,
  відповіді чату Jimmy AI, підписи слайдера.
- Компоненти: модальне вікно (кошик, обране, оформлення), FAQ-акордеон, слайдер, сповіщення.
- Перевірка форм: форма зворотного зв’язку, підписка на розсилку, оформлення замовлення.
- Кошик та обране зберігаються в localStorage.
